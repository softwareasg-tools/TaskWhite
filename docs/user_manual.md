# TaskWhite User Manual

> [!NOTE]
> Welcome to the comprehensive User Manual for TaskWhite.com. This document is designed to help you navigate, utilize, and master our AI-powered task management SaaS platform.

## 1. Introduction

Welcome to TaskWhite! TaskWhite is an AI-powered task management SaaS designed to simplify your workflow, enhance team collaboration, and boost productivity. This manual serves as your definitive guide to understanding and utilizing every feature TaskWhite has to offer. Whether you are a solo freelancer or part of a large enterprise team, this guide will help you get the most out of our platform.

## 2. Product Overview

TaskWhite.com is a modern, responsive web application that centralizes your projects, tasks, clients, and team members in one intuitive interface. By leveraging artificial intelligence, TaskWhite streamlines task generation and organization, allowing you to focus on execution rather than administration.

## 3. Key Features

TaskWhite is packed with powerful features tailored for efficiency:

- **AI Task Generation:** Automatically generate tasks based on project descriptions.
- **Dashboard:** A centralized hub for all your ongoing activities.
- **Task Archives & Recycle Bin:** Never lose track of completed or deleted tasks.
- **Client & Team Management:** Seamlessly collaborate with external clients and internal team members.
- **Task Types & Global Templates:** Standardize workflows across your organization.
- **Settings (Including Dark Mode):** Customize your experience to suit your preferences.
- **Bulk Operations:** Select all, delete, and modify multiple tasks simultaneously.
- **Multi-Authentication:** Secure login via Local Auth, Google, or Microsoft OAuth.

## 4. Account Creation

### Purpose
To establish a new user profile on TaskWhite.com to start managing tasks.

### Description
Creating an account grants you access to your personal or team workspace on TaskWhite.

### Prerequisites
- A valid email address or an active Google/Microsoft account.
- Internet access.

### Step-by-step instructions
1. Navigate to TaskWhite.com.
2. Click on the **Sign Up** button located at the top right corner.
3. Choose your preferred signup method:
   - **Local Auth:** Enter your email, create a password, and fill in your details.
   - **Google/Microsoft OAuth:** Click the respective button and authenticate via your provider.
4. Verify your email address (if using Local Auth).
5. Complete the onboarding questionnaire (**Assumption**).

### Expected outcome
You will be redirected to the TaskWhite Dashboard, ready to start creating projects.

### Screens
- Registration Screen
- OAuth Consent Screen
- Welcome/Onboarding Screen

### Tips
> [!TIP]
> Use Google or Microsoft OAuth for faster, more secure access without remembering an extra password.

### Warnings
> [!WARNING]
> Ensure you use a professional email address if you plan to invite team members or clients.

### Common mistakes
- Misspelling the email address during Local Auth registration.
- Forgetting the password immediately after creation.

### Troubleshooting
- **Did not receive verification email:** Check your spam/junk folder. Click "Resend Email" on the verification page.

## 19. Troubleshooting

**General Issues:**
- **App runs slowly:** Check your internet connection. TaskWhite is heavily reliant on real-time data syncing.
- **Changes not saving:** Look for a red "Offline" indicator (**Assumption**). Reconnect to the internet to sync changes.

**Feature-Specific Issues:**
- **AI Task Generation produces irrelevant results:** Provide a longer, more detailed project description. The AI relies on context.

## 20. FAQ

**Q: Is my data secure?**
A: Yes, we use industry-standard encryption. OAuth logins (Google/Microsoft) add an extra layer of security.

**Q: Can I recover a deleted task?**
A: Yes, deleted tasks go to the **Recycle Bin** where they can be restored.

**Q: How do Global Templates work?**
A: Global Templates allow you to create a standard set of tasks and structures that can be applied to any new project instantly.

**Q: How do I enable Dark Mode?**
A: Navigate to **Settings > Appearance** and toggle Dark Mode on.

## 21. Glossary

- **Task Archives:** A repository for completed tasks, keeping your active workspace uncluttered.
- **Recycle Bin:** A holding area for deleted items before permanent removal.
- **Global Templates:** Pre-defined project structures available across the entire workspace.
- **Task Types:** Categorizations for tasks (e.g., Bug, Feature, Review) to help organize workflows.

## 22. Keyboard Shortcuts (**Assumption**)

To speed up your workflow, TaskWhite supports basic keyboard shortcuts:

| Shortcut | Action |
| :--- | :--- |
| `Ctrl` + `N` / `Cmd` + `N` | Create a New Task |
| `Ctrl` + `F` / `Cmd` + `F` | Global Search |
| `Esc` | Close Modal/Dropdown |
| `Shift` + `Click` | Select multiple tasks for Bulk Operations |
| `Del` / `Backspace` | Move selected tasks to Recycle Bin |

> [!NOTE]
> Keyboard shortcuts are currently only supported on the desktop web version of TaskWhite.
