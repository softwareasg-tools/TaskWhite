# Roles and Permissions

Control who can see and do what within your TaskWhite workspace.

## Workspace Roles
*   **Workspace Owner:** Full control over billing, settings, and users.
*   **Admin:** Can manage users and global settings, but cannot access billing.
*   **Member:** Standard user who can create projects and tasks.
*   **Guest:** External user with limited access to specific projects only.

## Project Permissions
Within a project, you can set access levels:
*   **Public:** Visible to everyone in the workspace.
*   **Private to Members:** Only invited members can view and edit.
*   **Comment-Only:** Members can view and comment, but cannot edit tasks.

## Changing Permissions
Workspace Admins can adjust user roles from the **Members** tab in Workspace Settings. Project Owners can adjust project permissions from the Project Share menu.
