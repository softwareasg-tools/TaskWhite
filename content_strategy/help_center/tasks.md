# Working with Tasks

Tasks are the fundamental building blocks of work in TaskWhite. This guide covers how to manage task details effectively.

## Task Details
Every task has a dedicated details pane where you can add:
*   **Description:** Rich text formatting for instructions and context.
*   **Assignee:** The person responsible for completing the work.
*   **Due Date:** When the task needs to be finished.
*   **Custom Tags:** Track specific data points (e.g., Priority, Cost, Stage).
