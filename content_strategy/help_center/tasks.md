# Working with Tasks

Tasks are the fundamental building blocks of work in TaskWhite. This guide covers how to manage task details effectively.

## Task Details
Every task has a dedicated details pane where you can add:
*   **Description:** Rich text formatting for instructions and context.
*   **Assignee:** The person responsible for completing the work.
*   **Due Date:** When the task needs to be finished.
*   **Custom Fields:** Track specific data points (e.g., Priority, Cost, Stage).

## Subtasks
Break complex tasks into smaller, manageable steps using subtasks.
*   In the task details pane, click **Add Subtask**.
*   Subtasks can have their own assignees and due dates.

## Dependencies
Ensure work happens in the correct order by linking tasks.
*   Mark a task as "Waiting on" another task.
*   Assignees will be notified when unblocked.
