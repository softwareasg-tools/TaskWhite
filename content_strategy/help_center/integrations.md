# Integrations

Connect TaskWhite with the tools you already use to create a seamless workflow.

## Popular Integrations
*   **Communication:** Slack, Microsoft Teams
*   **File Storage:** Google Drive, Dropbox, OneDrive
*   **Development:** GitHub, GitLab, Jira
*   **CRM:** Salesforce, HubSpot

## How to Connect an App
1. Navigate to the **App Directory** in your workspace settings.
2. Search for the tool you want to connect.
3. Click **Install** and follow the authentication prompts.

## Building Custom Integrations
For custom workflows, use the TaskWhite API.
*   Visit our [Developer Portal](https://developers.taskwhite.com) for API documentation.
*   Generate personal access tokens from your Security Settings.
